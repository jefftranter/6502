Programming Pico firmware:
Remove a2pico from Apple II or power off computer.
Press and hold BOOTSEL button on Pico.
Connect Pico to computer via USB. Should detect and mount USB drive.
Copy .uf2 file to USB drive.

Firmware: A2retroNET-Link Version: 2026-09-19
---------------------------------------------

Emulates up to 8 SmartPort drives using microSD card as well as a
SuperSerial card (in printer mode). Drives map to slot where installed
as well as unused slots (2 drives per slot). Supported image types:
hdv, po, 2mg.

Disable SSC: SSC.HIDE.SYSTEM
Enable SSC: SSC.HIDE.SYSTEM
Run config (slot 7): CALL 51184 ($C7F0)

USB accesses microSD card via USB mass storage. To go into SSC mode,
put file ATINIT on boot disk.
On Linux, serial device appears as /dev/ttyACM0 and mass storage as
/dev/sda1.
Config file is A2retronet.txt on microSD card.
USB Pwr switch should be set to "off".

Hot keys during boot:
C   - Invoke configuration program.
N   - Continue autostart boot with next slot.
1-8 - Boot drive (as drive 1).

Configuration Program Keys:
<ESC>      Quit the configuration utility (and boot).
<SPACE>    Toggle between selecting a drive and selecting a disk image file.
<LEFT>     Select previous drive or disk image file (or directory).
<RIGHT>    Select next drive or disk image file (or directory).
<RETURN>   Insert selected disk image file in selected drive (or enter directory).
-          Remove disk image file from selected drive.
/          Go to root directory.
:          Switch between selecting from the USB key and the Micro SD card.
1-8        Directly select a drive.
0 or A-Z   Directly select a disk image file (or directory) with a
           matching name.
Control-E  Edit disk name.
Control-S  Enter Settings screen.
?          Show help screen

Firmware: A2retroNET-Drive Version: 2026-09-19
----------------------------------------------

Emulates up to 8 SmartPort drives using microSD card or external USB
key. Drives map to slot where installed as well as unused slots (2
drives per slot).
Use suitable cable to connect to USB key.
Configuration program is the same as above.
USB Pwr switch should be set to "on".

Firmware: softSP_A2Pico Version: 2026-09-02
-------------------------------------------

Allows Disk II interface to support SmartPort devices.
Also supports UniDisk 3.5" 800K drives.
Install a2pico in slot 7.
Need Disk II interface card in slot 6.
Connect SmartPort or UniDisk device to Disk II (may need adaptor).
On power up or PR#7 will boot SmartPort device.
Supports up to four drives, appearing as S7D1, S7D2, S4D1, and S4D2

Firmware: Appli-Card_A2Pico Version: 2026-09-19
-----------------------------------------------

Emulates a PCPI Appli-Card that contains a Z80 CPU and enables CP/M
operation.
Install card in any slot.
Boot suitable CP/M disk image (must be on storage external to a2pico,
not on USB or microSD). It can be frustrating to use with only one or
two 128K floppy drives; hard disk images are much better. You can use
a second a2pico to provide disk storage.
Depending on the drivers that are configured, an 80 column card is
detected and used.
Some images are in CP/M format and need to be booted directly. Some
disk images are in ProDOS format.
